How the pivot encodes the product

This example has three variables, so h = 1/48. Padding contributes mass 20h at payoff zero. Three compensation blocks each use mass h. After the low branch uses hx, the pivot supplies h(1 − x) and fills the lowest half. The pivot height after shifting rewards is 7 + σy for sign σ. Multiplying that height by the remaining mass introduces −σhxy.

Each CVaR equals 13/24 + σ(z − xy)/24. The two inequalities force the residual to be zero. The x and y sliders use eighths, and z uses sixty-fourths so every displayed product can be matched.
